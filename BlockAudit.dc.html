How the check works

Each template file is fetched and scanned for block mounts. Filled chips are blocks from the master file; outlined chips are individual components.

Possible drift flags a template that has its own nav or footer markup while mounting none from the master — the case worth fixing. Pages with no chrome at all (routers, docs, production sheets) are marked exempt, not drifting.

Verify by eye

The definitive test is still a live one: change something in the master nav block and reload a template. If it moves, it is linked.
